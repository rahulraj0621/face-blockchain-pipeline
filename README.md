# 🔍 Face Scan → Web Search → Blockchain Verification

An end-to-end Python pipeline that:

1. **Detects and encodes a face** from an input image
2. **Reverse-image searches** the web to find matching social media content
3. **Anchors a tamper-evident fingerprint** of the discovered data to the Ethereum blockchain — and re-verifies it

---

## 📐 Pipeline Architecture

```
input_image.jpg
      │
      ▼
┌─────────────────────────────┐
│  Stage 1 – Face Detection   │
│  face_recognition + dlib    │
│  → 128-d face encoding      │
│  → SHA-256 encoding hash    │
└────────────┬────────────────┘
             │
             ▼
┌──────────────────────────────────┐
│  Stage 2 – Reverse Image Search  │
│  SerpAPI Google Lens             │
│  → Matching social media posts   │
│  → Post metadata (url, title…)   │
└────────────┬─────────────────────┘
             │
             ▼
┌──────────────────────────────────────┐
│  Stage 3 – Blockchain Verification   │
│  Ethereum Sepolia Testnet + Infura   │
│  → SHA-256 fingerprint of face+post  │
│  → Store fingerprint in tx.input     │
│  → Re-fetch tx and verify match      │
└──────────────────────────────────────┘
             │
             ▼
  verification_report.json
```

Copy `.env.example` to `.env` and fill in the three values:

```bash

```

```ini
# .env
SERPAPI_KEY=<your SerpAPI key>          # https://serpapi.com  (100 free/month)
INFURA_PROJECT_ID=<your Infura ID>      # https://infura.io    (free tier)
```

1. Create a wallet via [MetaMask](https://metamask.io) and switch to **Sepolia Testnet**
2. Visit [sepoliafaucet.com](https://sepoliafaucet.com) and request free test ETH
3. Copy your private key from MetaMask → Account Details → Export Private Key

## ⛓️ Blockchain Details

| Property | Value |
|---|---|
| **Network** | Ethereum Sepolia Testnet |
| **Chain ID** | `11155111` |
| **RPC Provider** | Infura (`https://sepolia.infura.io/v3/<id>`) |
| **Storage method** | SHA-256 fingerprint stored in `input` field of a self-send tx |
| **Re-verification** | Fetch tx by hash, decode `input` field, compare to expected fingerprint |
| **Explorer** | https://sepolia.etherscan.io |

The fingerprint is computed as:
```
sha256(
  JSON.stringify({
    face_encoding_hash: "<sha256 of 128-d face encoding>",
    post: { source, title, url, thumbnail, ... },
    pipeline_version: "1.0.0",
    timestamp: "<ISO 8601>"
  }, sorted_keys)
)
```

Anyone with the same input image and post data can independently recompute this fingerprint and confirm it matches the on-chain record.

## ⚠️ Known Limitations

1. **Face recognition accuracy** — `face_recognition` uses HOG + dlib's 128-d model. It performs well under good lighting and frontal angles; accuracy degrades with extreme poses, low resolution, or heavy occlusion.

2. **Reverse image search** — SerpAPI's Google Lens returns the best publicly indexed visual matches. Private or recently posted content may not appear. Results vary by image and search index freshness.

3. **No cross-stage identity linking** — The pipeline does not *confirm* that the person in the search results is the same person in the input image. It links the face encoding hash to the post data cryptographically, not semantically.

4. **Testnet only** — Transactions are on Sepolia (testnet). Sepolia ETH has no real monetary value. For production use, switch `SEPOLIA_CHAIN_ID` and the Infura RPC URL to mainnet (and use real ETH).

5. **SerpAPI free tier** — Limited to 100 searches/month. Upgrade to a paid plan for heavier use.

6. **dlib installation** — Installing `dlib` on Windows requires CMake and Visual C++ Build Tools. See prerequisites above.
